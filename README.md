Credit Card Fraud Detection
Overview
A machine learning project designed to detect fraudulent credit card transactions using different classification algorithms.
Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- XGBoost
- Matplotlib
Models
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
Evaluation
Models are evaluated using Precision, Recall, F1-score, ROC-AUC and PR-AUC.
